# M-JARVIS WhatsApp Engine

An always-on WhatsApp bot for Mohammed Abbas, powered by Baileys and Supabase.

## Architecture

```
Your WhatsApp Messages → M-JARVIS Engine (Render.com) → Supabase DB → m-abbaslab.vercel.app Dashboard
```

## Quick Start

### 1. Install Dependencies
```bash
cd jarvis-whatsapp-engine
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
# Fill in your Supabase URL and Service Key
```

### 3. Set Up Supabase Table
Run this SQL in your **Supabase SQL Editor**:
```sql
CREATE TABLE whatsapp_messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  sender_number TEXT NOT NULL,
  sender_name TEXT,
  message_text TEXT NOT NULL,
  jarvis_reply TEXT,
  timestamp TIMESTAMPTZ DEFAULT NOW(),
  is_read BOOLEAN DEFAULT FALSE
);
```

### 4. Run Locally
```bash
npm start
```
Scan the QR code that appears in your terminal with your WhatsApp mobile app.

## Deploy to Render.com (Free, Always-On)

1. Push this `jarvis-whatsapp-engine` folder to a **new GitHub repo** (separate from m-abbaslab).
2. Go to [render.com](https://render.com) → New → **Web Service**.
3. Connect your new GitHub repo.
4. Set **Build Command**: `npm install`
5. Set **Start Command**: `npm start`
6. Add your Environment Variables (from `.env.example`).
7. Deploy! Render will keep your bot alive 24/7.

> **Note:** On first deploy, you'll need to check the Render logs to see the QR code and scan it once with your phone. After that, the auth session is saved and the bot reconnects automatically.

## How It Works

1. Someone sends a WhatsApp message to your number.
2. The JARVIS engine receives it instantly via the Baileys WebSocket.
3. JARVIS generates a smart reply based on keyword matching.
4. The reply is sent automatically.
5. The full conversation is logged to your Supabase `whatsapp_messages` table.
6. Your **Admin Dashboard** on Vercel reads from Supabase to display all messages.
